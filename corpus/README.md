# Corpus

`seed/` est le **corpus d'amorce** (conception §5.1) : des fiches courtes rédigées pour le
développement, à partir de connaissances vétérinaires générales.

**Non validé cliniquement.** Il sert uniquement à rendre le retrieval mesurable. Il sera remplacé
par le corpus curé (Elarif, Nino, vétérinaire partenaire) sans changer le pipeline.

Format : un fichier Markdown par fiche, une section `##` = un chunk.
